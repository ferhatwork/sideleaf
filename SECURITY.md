# Security Policy

## Supported Versions

Sideleaf is a client-side, local-first web application. Security updates and patches are applied to the latest release on the primary branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Sideleaf and the privacy of user data seriously. All user notes remain exclusively in the user's browser (IndexedDB) with zero remote telemetry or cloud sync.

If you discover a potential security vulnerability or privacy concern:

1. **Do not disclose publicly**: Please do not create public GitHub issues or public discussions for security reports.
2. **Submit privately**:
   - Use GitHub's private vulnerability reporting feature via [Security Advisories](https://github.com/ferhatwork/sideleaf/security/advisories/new).
   - Alternatively, contact the maintainer directly through their GitHub profile ([@ferhatwork](https://github.com/ferhatwork)).
3. **Include details**:
   - A clear description of the vulnerability and its potential impact.
   - Exact steps or minimal proof-of-concept to reproduce the behavior.
   - Operating system, browser, and version information.

### Responsible Disclosure

We appreciate responsible disclosure and will review reports promptly, investigate the issue, and release fixes before public notification.
