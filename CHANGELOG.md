# Changelog

All notable changes to Sideleaf will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-09-06

### Added
- Core digital paper work surface and thought capture interface.
- Instant thought capture overlay (`Ctrl+Space`) and quick-input bar.
- Sub-millisecond search palette (`Ctrl+K`) with multi-factor relevance ranking.
- Contextual workspaces and unorganized scratch surface.
- Portable versioned `.sideleaf` file export and import with backwards compatibility for legacy `.workpad` files.
- Standard Markdown (`.md`) workspace export.
- Full offline PWA support with service worker caching.
- Zero-dependency local desktop launchers (`Sideleaf.bat` for Windows, `Sideleaf.sh` for macOS/Linux).
- Complete English and Turkish bilingual localization.
- Automated test suites for branding, export/import validation, and database migration.
